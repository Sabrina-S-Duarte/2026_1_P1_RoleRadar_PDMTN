** Como executar o sistema **

1. Clone o repositorio (digite no terminal):
    git clone https://github.com/Sabrina-S-Duarte/2026_1_P1_RoleRadar_PDMTN.git

2. Entre na pasta da aplicação:
    cd .\role-radar\

3. Instale as dependencias do npm:
    npm install

4. Edite o arquivo 'chaves.js' em src/utils/ e troque os valores 'COLOQUE_SUA_CHAVE_AQUI':
    export const GEOAPIFY_KEY = 'CHAVE_GEOAPIFY'
    export const PRIMEUI_LICENSE = 'CHAVE_PRIMEUI'

5. Inicie a aplicação:
    npm run dev

6. No terminal aperte ctrl e clique no link que aparecer pra abrir a aplicação

!! Ao abrir o app, é preciso permitir o uso da localização para funcionar
